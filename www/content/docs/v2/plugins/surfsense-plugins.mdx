SurfSense runs its own plugins for reading the public web. Each one covers one site, so you connect, switch off and `@`-mention each on its own. They read only: none of them posts, buys, applies or changes anything.

## What they need

- **A SurfSense license.** Each shows "License required" in Browse. SurfSense sends your license key with each request, so you don't enter anything when you connect. See [License](/docs/v2/license) for a free trial and [pricing](/pricing).
- **`plugins.surfsense.com` allowed.** All of them run there, so allowing that host once, when SurfSense asks, covers every one.

Your own accounts on these sites are never used. Every plugin reads what a logged-out visitor can see.

## Connect them

<Steps>
<Step>
Import your license in **Settings › License**.
</Step>
<Step>
Open **Settings › Plugins › Browse**. Under **By SurfSense**, click **Connect** on each plugin you want.
</Step>
<Step>
Allow `plugins.surfsense.com` when asked.
</Step>
</Steps>

If your license is missing or refused, the plugin stays in Yours with **Needs a license**, **License expired**, **License revoked** or **License not recognized**, and the agent leaves it out. Import or renew the license and it comes back on its own.

## How they behave in a chat

- **No approval needed.** Every tool only reads, so it never asks before running. You can still set a tool to **Blocked**.
- **Some calls take minutes.** Reading many pages, or a site that pushes back, can take a few minutes. **Stop** in the chat ends the calls too.
- **Results stay in the chat.** Use **Save to Sources** on a step to keep its result.
- **Pick the plugin.** Type `@` and the plugin's name, such as `@reddit`, to make sure the agent uses it.

## Add from the web

The same plugins power **+ › Add from the web…** in Sources. Search Google or one site, or paste links, and add each result as a source. You don't need to connect the plugins for this, only to have a license and allow `plugins.surfsense.com`. Each plugin's page says which links it handles. Any other link is read as a web page by Web Crawl. See [Sources](/docs/v2/sources).

## What SurfSense sees

SurfSense counts how many calls each license makes to each plugin, so it can spot abuse and see which plugins to improve. It doesn't keep what you searched for or which pages you read.
