The **Sources** panel holds folders first, then sources, newest first. A note you write is a source like any file: searched, cited and ticked. See [Organize sources](/docs/v2/sources#organize-sources).

<Steps>
<Step>

### Write a note

Click **+** at the top of **Sources** and choose **New note**. Give it a title, write it, and click **Save note**. **Edit note**, in its **⋯** menu, reopens it later.

![The New note box with a title and a short note](/guides/organise-sources/01-new-note.webp)

</Step>
<Step>

### Make a folder

Choose **+ › New folder**, name it and click **Create**. A folder's own **⋯** menu makes folders inside it.

</Step>
<Step>

### Move, rename or delete

Each source's **⋯** menu has **Move to…**, **Rename** and **Delete**, with **Preview**, **Open** and **Show in folder** for files. You can also drag a source onto a folder.

![A note's menu open in Sources](/guides/organise-sources/02-source-menu.webp)

</Step>
<Step>

### Pick the folder

**Move to…** lists your folders. Pick one and click **Move**.

![The Move box with the Notes folder chosen](/guides/organise-sources/03-move-to.webp)

</Step>
<Step>

### Preview a PDF

**Preview** in a PDF's menu shows it inside SurfSense, in place of the left sidebar. **Open** opens SurfSense's copy in its own app instead.

![A PDF previewed inside SurfSense](/guides/organise-sources/04-preview.webp)

</Step>
</Steps>

Deleting a folder deletes everything in it, for good. The box says how many sources go with it.
