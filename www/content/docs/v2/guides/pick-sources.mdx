import { Step, Steps } from 'fumadocs-ui/components/steps';

<GuideVideo slug="pick-sources" poster="/guides/pick-sources/poster.webp" title="Ticking and unticking sources, one at a time and by folder" />

Every row in **Sources** has a tick box. Chat answers from the ticked sources, Studio makes things from them, and the agent may work on them. Each message uses the ticks on screen when you send it.

<Steps>
<Step>

### Untick a source

Untick a source to leave it out. Its folder's box clears, since not everything in it is ticked any more, and the chat box counts what's left, such as **2 sources**.

![One source unticked in its folder, and 2 sources in the chat box](/guides/pick-sources/01-untick.webp)

</Step>
<Step>

### Tick a whole folder

At the top of **Sources**, **Select all** ticks everything and **Clear** unticks everything. Tick a folder to use all of it, including files you add to it later. Untick one source inside a ticked folder to leave just that one out.

![The folder ticked with all its sources, and 3 sources in the chat box](/guides/pick-sources/02-folder.webp)

</Step>
</Steps>

Unticking every source leaves the model nothing to cite.
