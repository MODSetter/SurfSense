A chat answers from the sources ticked in **Sources** and cites the passage behind each point, so you can check it. This guide uses the security guides added in [Add files and folders](/docs/v2/guides/add-sources). [Chat](/docs/v2/chat) covers everything else a chat does.

<Steps>
<Step>

### Start a chat in Basic (Q&A)

Click **New chat**. Before the first message, open the mode picker in the chat box and choose **Basic (Q&A)**, which answers from your sources in one go. **Agentic** works in steps and can make files; see [Agent](/docs/v2/agent).

![The mode picker open over the chat box, with Basic (Q&A) and Agentic](/guides/ask-and-cite/01-mode.webp)

</Step>
<Step>

### Ask your question

Type it in the chat box and press Enter. SurfSense finds the passages that match and the model answers from them. Some models think first: the reply then shows how long they thought.

</Step>
<Step>

### Read the answer

Each point carries a small numbered chip: its citation. A point with no chip isn't backed by a passage from your sources. When none of them answers the question, the model says so before it answers from what it knows.

![The answer, with numbered citation chips after each point](/guides/ask-and-cite/02-answer.webp)

</Step>
<Step>

### Open a citation

Click a chip. The passage opens on the right, highlighted, with the text around it. **Open file** opens the original document.

![The cited passage highlighted in the right panel, beside the answer](/guides/ask-and-cite/03-citation.webp)

</Step>
</Steps>
