---
title: Keep projects apart with workspaces
description: Create a workspace for each project, switch between them, rename and delete them
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<GuideVideo slug="workspaces" poster="/guides/workspaces/poster.webp" title="Creating, switching, renaming and deleting a workspace" />

A workspace keeps one project's sources, chats and Studio outputs together, and a question in one never searches another. Your models, plugins, license and settings are shared by every workspace. See [Workspaces](/docs/v2/workspaces).

<Steps>
<Step>

### Create one

Click **+** in the narrow rail at the far left, type a name and click **Create**.

![The Create workspace box with a name typed in](/guides/workspaces/01-create.webp)

</Step>
<Step>

### Start using it

The new workspace opens straight away, empty, and the rail shows the first letters of its name.

![A new, empty workspace, with its letters in the rail](/guides/workspaces/02-new-workspace.webp)

</Step>
<Step>

### Switch, rename or delete

Click a workspace in the rail to switch to it. Switching doesn't stop anything: a reply being written in another workspace keeps going.

Right-click a workspace for **Rename** and **Delete**.

![A workspace's menu in the rail, with Rename and Delete](/guides/workspaces/03-workspace-menu.webp)

</Step>
<Step>

### Rename it

Choose **Rename**, type the new name and click **Rename**.

![The Rename workspace box with the new name typed in](/guides/workspaces/04-rename.webp)

</Step>
<Step>

### Delete it

Choose **Delete**, then **Delete workspace**. This deletes the workspace's chats, sources and Studio outputs for good, with no undo. Your own files elsewhere on your computer aren't touched.

![The question asking to delete the workspace, with Cancel and Delete workspace](/guides/workspaces/05-delete.webp)

</Step>
</Steps>
