SurfSense는 이미 가진 문서를 위한 무료 오픈소스 데스크톱 앱입니다. 끌어다 놓고 질문하면, 출처를 밝히는 답이 돌아옵니다. 같은 문서로 브리핑, 슬라이드, 보고서, 학습 가이드, 팟캐스트도 만듭니다. 전부 내 컴퓨터에서 돌아갑니다. 색인은 디스크에 있고, 모델은 내가 고르며, 앱은 아무것도 업로드하지 않습니다. 만들 계정도 없습니다.

**시작하기.** 내 컴퓨터용 설치 파일을 받은 다음, 가지고 있는 모델 키를 넣거나 앱이 로컬 모델을 받아 오게 합니다.

| 플랫폼 | 다운로드 |
|---|---|
| **Windows** x64 | [SurfSense-Setup.exe](https://github.com/MODSetter/SurfSense/releases/latest/download/SurfSense-Setup.exe) |
| **macOS** Apple Silicon | [SurfSense-arm64.dmg](https://github.com/MODSetter/SurfSense/releases/latest/download/SurfSense-arm64.dmg) |
| **Linux** x64 (AppImage) | [SurfSense.AppImage](https://github.com/MODSetter/SurfSense/releases/latest/download/SurfSense.AppImage) |
| **Linux** x64 (deb) | [SurfSense.deb](https://github.com/MODSetter/SurfSense/releases/latest/download/SurfSense.deb) |

모든 링크는 최신 릴리스를 가리키는 고정 주소입니다. [surfsense.com/downloads](https://www.surfsense.com/downloads)에서 고르거나 [모든 릴리스](https://github.com/MODSetter/SurfSense/releases)를 볼 수도 있습니다. AppImage는 자동으로 업데이트되고, deb는 그렇지 않습니다.

> [!NOTE]
> **호스팅 웹 앱을 쓰셨나요?** 서비스가 종료됩니다. 한 번 열어서 작업 공간을 내보낸 다음, 그 묶음을 데스크톱 앱으로 가져오세요. 문서, 폴더, 제목, 채팅 스레드가 함께 넘어옵니다. 내보내기 기간은 2026년 10월 18일에 닫힙니다. 자세한 내용은 [종료 안내 페이지](https://www.surfsense.com/sunset)에 있습니다.

## SurfSense가 만드는 것

문서 몇 개와 형식을 고릅니다. 앱은 고른 자료로, 내 컴퓨터에서 그것을 씁니다.

| 형식 | 받게 되는 것 | 필요한 것 |
|---|---|---|
| **요약** | 고른 자료의 구조화된 브리프 | 생성 모델 |
| **플래시카드** | 한 장씩 넘기는 대화형 덱 | 생성 모델 |
| **퀴즈** | 답이 있는 객관식 문제 | 생성 모델 |
| **마인드맵** | 확대하고 접을 수 있는 Markmap | 생성 모델 |
| **슬라이드** | 편집할 수 있는 `.pptx`. 덱을 찍은 그림이 아님 | 생성 모델 |
| **문서** | 편집할 수 있는 `.docx` 보고서 | 생성 모델 |
| **스프레드시트** | 자료에서 뽑은 표의 `.xlsx` | 생성 모델 |
| **웹 페이지** | 그 자체로 완결된 HTML 페이지 | 생성 모델 |
| **PDF** | 조판된 PDF | 생성 모델 |
| **팟캐스트** | 두 진행자의 음성 대화. Kokoro-82M이 오프라인으로 읽음 | 생성 모델 + 함께 제공되는 음성 |
| **이미지** | 자료를 위한 삽화 | 이미지 모델 + 생성 모델 |
| **인포그래픽** | 한 장으로 된 시각 요약 | 이미지 모델 + 생성 모델 |

어떤 일은 형식이 하나로는 부족합니다. 학습 가이드는 같은 자료에 대한 요약, 플래시카드, 퀴즈입니다. 고객 브리핑은 보통, 발표에 쓰는 덱과 그 뒤에 보내는 요약입니다. 영상 개요는 아직 없습니다.

## 모든 것은 내 컴퓨터에 남습니다

사건 기록, 고객 작업 문서, 인터뷰 녹취, 내부 사양, 미발표 연구, 한 학기 분의 강의 노트. 사람들이 이런 자료에 이 앱을 씁니다. 그 전부에 질문할 수 있고, 모든 답은 나온 자료를 밝힙니다. 앱은 그중 아무것도 업로드하지 않습니다.

- **색인은 로컬입니다.** 파싱, 청크 나누기, 임베딩은 내 컴퓨터에서 이루어지고, `~/.surfsense` 아래 SQLite에 들어갑니다. SurfSense는 사본을 두지 않고, 무엇을 물었는지도 기록하지 않습니다.
- **모든 역할이 로컬에서 돕니다.** 문서 파서, 검색 모델, 팟캐스트 음성은 설치 파일 안에 있습니다. 채팅과 이미지 생성은 로컬 서버로 들어오고, 가중치는 한 번 받으면 됩니다. 계정이나 API 키 없이 글, 오디오, 그림을 만들 수 있습니다. 확인 방법은 네트워크를 끈 채 PDF를 넣는 것입니다.
- **나가는 연결은 기본으로 꺼져 있습니다.** 외부 연결 패널이 앱이 닿을 수 있는 대상을 모두 나열하고, 원하는 것만 켭니다.
- **원격 측정 없음, 충돌 보고 없음.** 밖으로 나가는 것이 없으니, 찾을 옵트아웃도 없습니다.

SurfSense는 이것이 특정 규정을 만족하는지 알려 주지 못합니다. 그것은 자신의 통제와 규제 기관에 달렸습니다. 앱이 말해 줄 수 있는 것은, 문서가 어느 컴퓨터에 있는지뿐입니다.

## SurfSense 비교

"로컬 NotebookLM"이라 불리는 제품은 세 종류이고, 답하는 질문이 다릅니다. 어느 것도 나쁜 도구는 아닙니다. 마지막에 손에 남는 것이 다를 뿐입니다.

**Jan, AnythingLLM, Open WebUI, LM Studio와 비교하면.** 이들은 모델을 로컬에서 실행하고, 그와 이야기할 곳을 줍니다. SurfSense가 답하는 것은 그다음 질문입니다. 거기서 완성된 문서를 어떻게 꺼내는가. 함께 써도 됩니다. SurfSense를 OpenAI 호환 엔드포인트라면 어디든, 그들이 제공하는 것까지 포함해 가리키면 됩니다.

**RemNote, Quizlet, NoteGPT, StudyFetch, Gamma와 비교하면.** 이들은 결과물을 만들고, 우리 것보다 보기 좋은 것도 있습니다. 대가는 자료가 가는 곳입니다. 업로드하고, 매달 돈을 내고, 파일은 다른 사람의 계정에 있습니다.

**Google NotebookLM과 비교하면.** 그쪽에는 이미 플래시카드, 퀴즈, 마인드맵, 오디오 개요가 있어서, 둘 다 거의 같은 것을 만듭니다. 차이는 일을 하는 컴퓨터가 누구의 것인지, 그리고 어떤 모델을 붙일 수 있는지입니다.

| | Google NotebookLM | SurfSense |
|---|---|---|
| 오프라인 / 네트워크 분리로 동작 | 아니요 | **예** |
| 문서가 내 컴퓨터를 떠남 | 떠남 | **떠나지 않음** |
| 계정 | Google 계정 필요 | **없음** |
| 오픈소스 | 아니요 | **Apache-2.0** |
| 가격 | 무료 구간. Pro 월 $19.99. Ultra 월 $249.99 | **앱은 무료** |
| 모델 | Gemini만 | OpenAI 호환 API 전부, 또는 로컬 모델 |
| 자료 한도 | 자료 50개에서 600개, 각각 50만 단어 | 디스크에 들어가는 만큼 |
| 오디오와 영상 개요 | 둘 다 있고, 더 낫다 | 오디오는 있음, 오프라인. 영상은 아직 없음 |

오디오 품질은 NotebookLM이 앞서고, 영상도 있습니다. 자료가 Google 서버에 있어도 괜찮다면 그것을 쓰세요. 그렇지 않다면, 이쪽이 업로드 없는 같은 종류의 도구입니다.

## 빠른 시작

Docker도, 터미널도, GPU도, compose 파일도 필요 없습니다.

1. **설치 파일을 받습니다.** 위 표에 있습니다. 서명되어 있어서 운영체제가 막지 않습니다.
2. **모델을 고릅니다.** 로컬 모델을 앱이 받게 두거나(Qwen3, 여섯 가지 크기, 최소 0.5 GB), OpenAI 호환 API의 베이스 URL과 키를 붙입니다. 선택 화면은 내 컴퓨터가 모델을 돌릴 수 있는지 확인한 뒤에 보여 줍니다. 넣은 키는 암호화되어 저장되고, 비밀은 운영체제 키체인에 있습니다.
3. **문서를 넣습니다.** PDF, Office 파일, 이미지는 내 컴퓨터에서 파싱됩니다.
4. **질문합니다.** 모든 답이 나온 자료를 밝힙니다.
5. **Studio를 열고,** 형식을 고른 다음, 파일을 가져갑니다.

느린 부분은 다운로드입니다. 설치 파일에 파서, 검색 모델, 팟캐스트 음성, 로컬 모델 서버가 들어 있어서, 네트워크가 꺼져 있어도 앱이 동작합니다.

## 문서와 커뮤니티

앱과 그 업데이트는 무료입니다. 라이선스가 더하는 것은 플러그인과 우선 지원뿐이고, 그 밖에는 아무것도 잠그지 않습니다. 라이선스가 만료되어도 앱과 이후의 모든 업데이트는 그대로 남습니다. [요금](https://www.surfsense.com/pricing)을 보세요.

이 저장소의 Docker 스택(`surfsense_backend`, `surfsense_web`, compose 파일)은 계속 오픈소스이고 설치할 수 있으며, **커뮤니티가 지원합니다. SLA는 없고, 뒤에 호스팅 서비스도 없습니다.** 새 사용자에게 지원되는 경로는 데스크톱 앱입니다.

- 설치, 모델, Studio 형식, 자체 호스팅은 [문서](https://www.surfsense.com/docs)
- [호스팅 앱에서 가져오기](https://www.surfsense.com/sunset)
- 호스팅 스크레이퍼 API를 위한 [MCP 서버](./surfsense_mcp)
- 도움과 아이디어는 [Discord](https://discord.gg/ejRNvftDp9), 방향은 [Discussions](https://github.com/MODSetter/SurfSense/discussions), 재현되는 버그는 [Issues](https://github.com/MODSetter/SurfSense/issues)
- 이 다음을 따라가려면 **저장소에 스타를 누르세요**

## 기여

풀 리퀘스트를 환영하며, 전체 흐름은 [CONTRIBUTING.md](CONTRIBUTING.md)에 있습니다. 짧게 말하면 이렇습니다.

- **할 일을 찾습니다.** [`good first issue`](https://github.com/MODSetter/SurfSense/labels/good%20first%20issue) 또는 [`help wanted`](https://github.com/MODSetter/SurfSense/labels/help%20wanted) 라벨이 붙은 이슈, 또는 [`docs/architecture/`](docs/architecture/overview.md) 각 문서 끝의 Known gaps(알려진 빈틈) 목록의 한 줄.
- **먼저 어떻게 동작하는지 읽습니다.** [`docs/`](docs/README.md)가 각 기능과 왜 그렇게 만들어졌는지를 설명하고, [`docs/ROADMAP.md`](docs/ROADMAP.md)가 메인테이너가 작업 중인 것을 보여 줍니다.
- **`dev`에 PR을 엽니다.** 버그 수정과 문서는 사전 논의가 필요 없습니다. 새 기능은 짧은 설계 제안으로 시작합니다. 데스크톱 앱은 [`surfsense_local/`](./surfsense_local)에 있고, 그 README가 개발 순환을 설명합니다.
