## SurfSense's Next Chapter: Open Web Research for AI Agents

We announced a new direction for SurfSense: giving AI agents the primitives to research the open web, through platform connectors for live data, an MCP server and automations, while everything existing users relied on kept working.

Since then SurfSense has become a free desktop app, and the live-data connectors ship as [plugins](/plugins) for it. See the entries for v2.0.0 and v2.2.1 above.
