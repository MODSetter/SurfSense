SurfSense — бесплатное настольное приложение с открытым кодом для документов, которые уже есть. Перетащите их внутрь, задайте вопросы и получите ответы со ссылкой на источник, а затем превратите те же документы в брифинг, презентацию, отчёт, учебное руководство или подкаст. Всё это работает на вашем компьютере: индекс лежит на диске, модель выбираете вы, и приложение ничего не отправляет. Аккаунт создавать не нужно.

**С чего начать.** Скачайте установщик для своего компьютера, затем принесите свой ключ модели или пусть приложение само скачает локальную модель.

| Платформа | Скачать |
|---|---|
| **Windows** x64 | [SurfSense-Setup.exe](https://github.com/MODSetter/SurfSense/releases/latest/download/SurfSense-Setup.exe) |
| **macOS** Apple Silicon | [SurfSense-arm64.dmg](https://github.com/MODSetter/SurfSense/releases/latest/download/SurfSense-arm64.dmg) |
| **Linux** x64 (AppImage) | [SurfSense.AppImage](https://github.com/MODSetter/SurfSense/releases/latest/download/SurfSense.AppImage) |
| **Linux** x64 (deb) | [SurfSense.deb](https://github.com/MODSetter/SurfSense/releases/latest/download/SurfSense.deb) |

Каждая ссылка всегда ведёт на самый новый выпуск. Можно также выбрать на [surfsense.com/downloads](https://www.surfsense.com/downloads) или просмотреть [все выпуски](https://github.com/MODSetter/SurfSense/releases). AppImage обновляется сам; deb нет.

> [!NOTE]
> **Пользовались размещённым веб-приложением?** Его выводят из работы. Откройте его один раз, экспортируйте рабочие пространства, затем импортируйте пакет в настольное приложение. Документы, папки, названия и ветки чатов переносятся все. Окно экспорта закрывается 18 октября 2026 года. Подробности на [странице закрытия](https://www.surfsense.com/sunset).

## Что делает SurfSense

Выберите несколько документов и формат. Приложение пишет результат из выбранных источников, на вашем компьютере.

| Формат | Что получается | Нужно |
|---|---|---|
| **Сводка** | Структурированный бриф выбранных источников | модель генерации |
| **Карточки** | Интерактивная колода, по одной карточке | модель генерации |
| **Тест** | Вопросы с вариантами ответа и сами ответы | модель генерации |
| **Ментальная карта** | Масштабируемая сворачиваемая Markmap | модель генерации |
| **Слайды** | Редактируемый `.pptx`, не картинка презентации | модель генерации |
| **Документ** | Редактируемый отчёт `.docx` | модель генерации |
| **Таблица** | `.xlsx` таблиц, извлечённых из источников | модель генерации |
| **Веб-страница** | Самодостаточная страница HTML | модель генерации |
| **PDF** | Свёрстанный PDF | модель генерации |
| **Подкаст** | Аудиоразговор двух ведущих, озвученный без сети моделью Kokoro-82M | модель генерации + аудиомодель |
| **Изображение** | Иллюстрация к материалу | модель изображений + модель генерации |
| **Инфографика** | Наглядная сводка на одной панели | модель изображений + модель генерации |

Некоторым задачам нужно больше одного формата. Учебное руководство — это сводка, колода карточек и тест по тому же набору источников, а клиентский брифинг обычно состоит из презентации, с которой выступают, и сводки, которую отправляют после. Видеообзоры ещё не сделаны.

## Всё остаётся на вашем компьютере

Сюда направляют материалы дел, рабочие бумаги клиентов, расшифровки интервью, внутренние спецификации, неопубликованные исследования и конспекты лекций за целый семестр. Можно задавать вопросы по всему этому, и каждый ответ называет источник, из которого он взят. Приложение ничего из этого не загружает.

- **Индекс локальный.** Разбор, нарезка и эмбеддинги происходят на компьютере, в SQLite по пути `~/.surfsense`. SurfSense не хранит копию и не ведёт журнал того, что спрашивали.
- **Каждая роль может работать локально.** Разборщик документов, модель поиска и голос подкаста лежат внутри установщика. Чат и генерация изображений поставляются как локальные серверы, чьи веса скачиваются один раз, поэтому текст, звук и картинки получаются без аккаунта и без ключа API. Мы проверяем это, принимая PDF при отключённой сети.
- **Исходящие подключения выключены по умолчанию.** Панель исходящих адресов перечисляет каждое место, до которого приложение может достучаться, и включаются только нужные.
- **Никакой телеметрии и никаких отчётов о сбоях.** Ничто не связывается с разработчиком, поэтому нет переключателя, который пришлось бы искать.

SurfSense не скажет, удовлетворяет ли это конкретному регулированию. Это зависит от собственных мер контроля и от регулятора. Приложение может сказать только одно: на каком компьютере лежат документы.

## Как SurfSense сравнивается

Три вида продуктов называют «локальным NotebookLM», и они отвечают на разные вопросы. Ни один из них не плохой инструмент. На руках в итоге остаётся разное.

**В сравнении с Jan, AnythingLLM, Open WebUI, LM Studio.** Они запускают модель локально и дают место, где с ней можно говорить. SurfSense отвечает на следующий вопрос: как получить из этого готовый документ? Их можно использовать вместе, направив SurfSense на любую конечную точку, совместимую с OpenAI, в том числе на их собственную.

**В сравнении с RemNote, Quizlet, NoteGPT, StudyFetch, Gamma.** Они тоже делают готовые материалы, и некоторые выглядят лучше наших. Расплата в том, куда уходит материал: его загружают, платят каждый месяц, и файлы живут в чужом аккаунте.

**В сравнении с Google NotebookLM.** Там уже есть карточки, тесты, ментальные карты и аудиообзоры, так что оба делают по большей части одно и то же. Разница в том, чей компьютер делает работу и на какую модель можно его направить.

| | Google NotebookLM | SurfSense |
|---|---|---|
| Работает без сети / изолирован от сети | Нет | **Да** |
| Документы покидают компьютер | Да | **Нет** |
| Нужен аккаунт | Аккаунт Google | **Не нужен** |
| Открытый код | Нет | **Apache-2.0** |
| Цена | Бесплатный уровень; Pro $19.99 в месяц; Ultra $249.99 в месяц | **Приложение бесплатно** |
| Модели | Только Gemini | Любой совместимый с OpenAI API, или локальная модель |
| Лимиты источников | от 50 до 600 источников, по 500,000 слов | Сколько вмещает диск |
| Аудио- и видеообзоры | Да, и лучше | Аудио да, без сети; видео ещё нет |

NotebookLM выигрывает по качеству звука, и у него есть видео. Если устраивает, что источники лежат на серверах Google, пользуйтесь им. Если нет, здесь тот же род инструмента, без загрузки наружу.

## Быстрый старт

Не нужны Docker, терминал, GPU и compose-файл.

1. **Скачайте установщик** из таблицы выше. Он подписан, так что система не станет с ним воевать.
2. **Выберите модель.** Пусть приложение само скачает локальную (Qwen3 в шести размерах, от 0.5 GB) или вставьте базовый URL и ключ любого API, совместимого с OpenAI. Выбор проверяет, что компьютер потянет модель, прежде чем предлагать её, а любой ключ хранится зашифрованным, и секрет лежит в связке ключей ОС.
3. **Перетащите документы.** Приложение разбирает PDF, файлы Office и изображения на компьютере.
4. **Задавайте вопросы.** Каждый ответ называет источник, из которого он взят.
5. **Откройте Studio,** выберите формат, заберите файл.

Скачивание — медленная часть, потому что установщик несёт разборщик, модель поиска, голос подкаста и локальные серверы моделей, и поэтому приложение работает с выключенной сетью.

## Документация и сообщество

Приложение и его обновления бесплатны. Лицензия добавляет плагины и приоритетную поддержку и больше ничего не закрывает, поэтому истёкшая лицензия всё равно оставляет приложение и каждое будущее обновление. См. [цены](https://www.surfsense.com/pricing).

Стек Docker в этом репозитории (`surfsense_backend`, `surfsense_web`, compose-файлы) остаётся открытым и устанавливаемым и **держится на сообществе: без соглашения об уровне сервиса и без размещённой службы за ним.** Настольное приложение — поддерживаемый путь для новых пользователей.

- [Документация](https://www.surfsense.com/docs) по установке, моделям, форматам Studio и самостоятельному хостингу
- [Импорт из размещённого приложения](https://www.surfsense.com/sunset)
- [Сервер MCP](./surfsense_mcp) для размещённого API скрейпера
- [Discord](https://discord.gg/ejRNvftDp9) для помощи и идей, [Discussions](https://github.com/MODSetter/SurfSense/discussions) для направления, [Issues](https://github.com/MODSetter/SurfSense/issues) для воспроизводимых ошибок
- **Поставьте звезду репозиторию**, если хотите следить, куда это идёт

## Участие

Запросы на слияние приветствуются, и [CONTRIBUTING.md](CONTRIBUTING.md) проводит по всему пути. Коротко:

- **Найти, над чем работать:** задача с меткой [`good first issue`](https://github.com/MODSetter/SurfSense/labels/good%20first%20issue) или [`help wanted`](https://github.com/MODSetter/SurfSense/labels/help%20wanted), или строка из списка Known gaps (известные пробелы) в конце каждого документа в [`docs/architecture/`](docs/architecture/overview.md).
- **Сначала прочитайте, как это устроено:** [`docs/`](docs/README.md) объясняет каждую возможность и почему она сделана так, а [`docs/ROADMAP.md`](docs/ROADMAP.md) показывает, над чем работают сопровождающие.
- **Откройте запрос на слияние в `dev`.** Исправления ошибок и документация не требуют обсуждения заранее. Новая возможность начинается с короткого проектного предложения. Настольное приложение живёт в [`surfsense_local/`](./surfsense_local), и его README описывает цикл разработки.
