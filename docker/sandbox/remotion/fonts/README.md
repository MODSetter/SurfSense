# Offline font palette

Variable TTFs vendored from the Google Fonts repository:

- `Inter.ttf` — Inter (`ofl/inter`)
- `Lora.ttf` — Lora (`ofl/lora`)
- `JetBrainsMono.ttf` — JetBrains Mono (`ofl/jetbrainsmono`)

All three are distributed under the included SIL Open Font License (`OFL.txt`).
These are the only font families supported by sandbox-authored scenes.
