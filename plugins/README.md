# Plugins

A plugin is an MCP server that gives SurfSense's models tools. Remote plugins, hosted by their publishers, come first; the design is the [plugins proposal](../docs/proposals/plugins/README.md).

| Folder | What it holds |
|---|---|
| [`bundles/`](bundles/README.md) | Deferred. The earlier, local design's SDK, CLI, manifest rules and example, kept as the base for plugins that run on the user's machine |

SurfSense's own plugin servers and the registry land here as the proposal is built.
