lameenc and LAME in this application
====================================

The worker encodes podcast episodes to MP3 with lameenc, a Python extension
module that statically links the LAME MP3 encoder. The module ships as its own
file beside this folder, and may be replaced with a build of your own.

lameenc 1.8.4, LGPL-3.0
  Source: https://github.com/chrisstaite/lameenc/tree/v1.8.4
  Licence: lameenc-LGPL-3.0.txt, with GPL-3.0.txt, which LGPL-3.0 builds on.

LAME 3.100, LGPL (GNU Library General Public License, version 2)
  Source: the official release, lame-3.100.tar.gz,
  https://sourceforge.net/projects/lame/files/lame/3.100/
  Licence: LAME-COPYING. Copyright notice: LAME-README.
