Task: organise the sources below into a mind map, with as many main branches as the material needs, at most $ceiling, nested as deep as it needs.
$focus
Work in this order:

1. Read every source and note what each one is about and the figures and names it states.
2. Group what you found into themes that hold the material — themes the sources support, not headings you expect to see.
3. Under each theme, hang the specifics, each a few words, and go a level deeper wherever a specific has parts of its own. Put a figure or a date in the label where one exists.
4. Check every label against the sources and drop any you cannot point to.

Grounding rules:

- Use only facts the sources state. No outside knowledge, no estimates, no plausible-sounding filler.
- Labels are short — a few words each, never a sentence.
- If a source calls something proposed or pending, label it that way.

Write it as a Markdown outline: the title as `# Title`, then one `- ` bullet per label, each level indented two spaces deeper than its parent.

Worked example — a different topic in the same shape. Copy the structure, never the content:

# Leeds-Hull electrification
- Schedule
  - Full electrification 2031
  - Signalling rescoped
    - Moved from 2029

Return only the outline. Nothing before it, nothing after it.
